# αvβ1 de novo 캠페인 v2 재실행 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 순수 non-RGD 학습셋과 두 개의 TL 아암 위에서, AutoDock-GPU + PLIP 상호작용 게이트로 αvβ1 리드를 다시 선별하고 선택성까지 판정 기준에 포함시킨다.

**Architecture:** 기존 REINVENT4 퍼널(TL → RL → 샘플링 → 속성 윈도 → 도킹 → 게이트 → ADMET → 리드)의 뼈대를 유지한 채 네 지점을 교체한다 — (1) `curate_actives.py`의 tool-compound 강제 주입을 제거해 core를 규칙만으로 정의, (2) prior만 다른 두 아암(TL-A′/TL-C)을 끝까지 병행, (3) Uni-Dock/거리 게이트를 AutoDock-GPU/PLIP 상호작용 게이트로 교체, (4) 리드 선정을 3단 필터 + 선택성 rank-sum으로 바꾸고 아이소폼 역도킹을 신설. 각 계산 단계 앞에는 사전등록된 검증 게이트가 있고, 통과하지 못하면 그 단계를 쓰지 않는다.

**Tech Stack:** Python 3 / RDKit / REINVENT4 v4.5.11 / torch 2.5.1+cu118 / AutoDock-GPU + autogrid4 / Open Babel / Meeko / PLIP / ADMET-AI / wandb / pytest·unittest / SLURM (K-BDS `8gpu`, `cpu64`)

**Spec:** `docs/superpowers/specs/2026-09-28-avb1-rerun-design.md`

## Global Constraints

- REINVENT4는 **v4.5.11**에 고정. TL config의 `GlobalConfig`는 pydantic `extra="forbid"` — 알 수 없는 키는 하드 기동 오류다. `isomeric_smiles` 키는 존재하지 않는다.
- de novo prior의 어휘는 **33토큰이며 입체화학 토큰이 없다.** 모든 `.smi` 입력은 평탄화(flattened)한다. 입체 정보는 `actives_annotated.csv`의 `smiles` 컬럼에만 보존한다.
- 모든 지문 비교·Murcko 판정 전에 **토토머 정규화**(`rdMolStandardize.TautomerEnumerator().Canonicalize()`)를 **참조 측과 측정 측에 동일하게** 적용한다.
- 비교 대상은 **PLN-1474 단일**이다 — affinity·투과성·독성·선택성 네 축 모두.
- 수용체 PDBQT는 **`obabel -xr -h`**로 만든다. **`obabel -p 7.4` 금지** (칼슘 6개를 제거하고도 점수는 정상으로 보인다).
- RMSD는 **`rdMolAlign.CalcRMS`** 로만 계산한다. 인덱스 기반 좌표 뺄셈 금지.
- PLIP은 **GPU 구현이 없다.** K-BDS **`cpu64`** 파티션에서 실행한다. `8gpu`는 GPU 사용량과 무관하게 시간당 8 node-hour를 과금한다.
- `max_steps = 1000` (문서상 "600 steps"는 오류).
- **§2 성공 판정 임계값은 사후에 변경하지 않는다.** §9 리드 선정 임계값만 완화 가능하며 모든 완화는 `results/v2_threshold_ledger.md`에 기록한다.
- 테스트는 `unittest`, `tests/` 아래, `sys.path.insert(0, .../scripts)` 관례를 따른다.

## Review Focus

- **PLN-1474가 자기 자신의 게이트를 통과하지 못하는 경우** — 새 PLIP 게이트에서 PLN-1474가 passing pose를 하나도 내지 못하면 affinity 기준값이 존재하지 않아 필터 체인 전체가 무너진다. Task 15가 이를 명시적으로 검사하고 실패 시 중단해야 한다.
- **PLIP이 어떤 상호작용도 보고하지 않는 포즈** — 파서가 예외로 죽지 않고 빈 상호작용 집합을 반환해야 한다. v1에서 "점수 누락이 포즈 전체를 날리는" 같은 종류의 회귀가 있었다(Task 12).
- **수소 추가/복합체 생성에 실패하는 포즈** — 한 포즈의 실패가 배치 전체를 중단시키면 안 되고, 실패는 기록되되 나머지는 진행해야 한다(Task 11).
- **autogrid4 맵이 검색 박스를 덮지 못하는 경우** — 리간드가 그리드 밖으로 나가면 AutoDock-GPU는 오류 없이 이상한 에너지를 반환한다. 맵 범위와 박스가 일치하는지 검사해야 한다(Task 8).
- **선택성 역도킹에서 검증을 통과한 아이소폼이 0개인 경우** — rank-sum이 빈 집합 위에서 계산되어 0으로 나누거나 전원 동점이 되면 안 되고, 판정 기준 7번을 `unevaluable`로 기록해야 한다(Task 19).

```python
# tests/test_curate_core_membership.py
import sys
import unittest
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent / "scripts"))

from rdkit import Chem, RDLogger

RDLogger.DisableLog("rdApp.*")

import curate_actives

CORE = "data/actives_core.smi"
PANEL = "data/benchmark_panel.smi"

RGD_TOOLS = {"bexotegrast", "CWHM-12", "GLPG0187", "PLN-1474"}


def read_smi(path):
    rows = []
    for line in open(path):
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        smiles, label = line.split("\t")
        rows.append((smiles, label))
    return rows


class TestCoreIsRuleDerived(unittest.TestCase):
    """core 멤버십이 하드코딩 주입 없이 규칙만으로 결정되는지.

    v1은 TOOL_COMPOUNDS 4종을 chemotype 규칙과 potency 규칙을 모두 우회해
    core에 주입했다. 그 결과 '왜 섞였는가'가 코드가 아니라 주석에만 있었다.
    """

    def test_core_has_no_rgd_tool_compounds(self):
        labels = {label for _, label in read_smi(CORE)}
        self.assertEqual(labels & RGD_TOOLS, set())

    def test_core_is_25_molecules(self):
        self.assertEqual(len(read_smi(CORE)), 25)

    def test_every_core_molecule_is_non_rgd(self):
        """curate_actives의 여섯 Arg-mimic SMARTS 중 어느 것도 걸리지 않아야 한다."""
        patterns = {name: Chem.MolFromSmarts(smarts)
                    for name, smarts in curate_actives.ARG_MIMIC_HEADS.items()}
        for name, pattern in patterns.items():
            self.assertIsNotNone(pattern, f"SMARTS가 파싱되지 않음: {name}")
        flagged = []
        for smiles, label in read_smi(CORE):
            mol = Chem.MolFromSmiles(smiles)
            hits = [n for n, p in patterns.items() if mol.HasSubstructMatch(p)]
            if hits:
                flagged.append((label, hits))
        self.assertEqual(flagged, [])

    def test_every_core_molecule_carries_a_carboxylic_acid(self):
        acid = Chem.MolFromSmarts(curate_actives.CARBOXYLIC_ACID)
        missing = [label for smiles, label in read_smi(CORE)
                   if not Chem.MolFromSmiles(smiles).HasSubstructMatch(acid)]
        self.assertEqual(missing, [])


class TestPanel(unittest.TestCase):
    """패널은 목표 프로파일 참조군 4종. pan-αv 화합물과 C8은 제외한다."""

    def test_panel_is_exactly_four_named_compounds(self):
        labels = {label for _, label in read_smi(PANEL)}
        self.assertEqual(labels,
                         {"A1AFA", "PLN-1474", "CHEMBL4649232", "bexotegrast"})

    def test_pan_av_compounds_are_absent(self):
        """CWHM-12는 αvβ8에 9배(0.2 vs 1.8 nM), αvβ3에 2.25배 더 강하다.
        GLPG0187은 완전 평탄한 pan-αv다. 목표 프로파일 참조군이 아니다."""
        labels = {label for _, label in read_smi(PANEL)}
        self.assertNotIn("CWHM-12", labels)
        self.assertNotIn("GLPG0187", labels)

    def test_c8_is_absent(self):
        labels = {label for _, label in read_smi(PANEL)}
        self.assertNotIn("C8", labels)


if __name__ == "__main__":
    unittest.main()
```

```python
# tests/test_curate_annotations.py
import csv
import unittest

ANNOTATED = "data/actives_annotated.csv"


def load():
    with open(ANNOTATED) as handle:
        return {row["identifier"]: row for row in csv.DictReader(handle)}


class TestEndpointProvenance(unittest.TestCase):
    """v1 §3.4는 CHEMBL4649232를 'IC50 0.166 nM'으로 적었으나 실제로는 Ki다.
    출처도 1차 논문이 아니라 리뷰이며, 1차 출처는 따로 있다."""

    @classmethod
    def setUpClass(cls):
        cls.rows = load()

    def test_chembl4649232_endpoint_is_ki_not_ic50(self):
        row = self.rows["CHEMBL4649232"]
        self.assertEqual(row["endpoint_type"], "Ki")

    def test_chembl4649232_primary_source_is_the_chemmedchem_paper(self):
        """ChEMBL의 출처 문서 CHEMBL4602673은 Zheng & Leftheris 2020 리뷰이고,
        그 안의 compound 38이다. 1차 출처는 리뷰의 참고문헌 141이다."""
        row = self.rows["CHEMBL4649232"]
        self.assertIn("ChemMedChem", row["primary_source"])
        self.assertIn("2019", row["primary_source"])

    def test_compound_25_is_identified(self):
        """CHEMBL5532604 = Sabat compound 25. pIC50 9.5는 논문 Table 3의
        ELISA 값과 일치한다. 재발견하지 않도록 기록해 둔다."""
        row = self.rows["CHEMBL5532604"]
        self.assertEqual(row["paper_id"], "Sabat2024:25")
        self.assertEqual(row["pIC50"], "9.5")

    def test_every_row_declares_an_endpoint_type(self):
        blank = [ident for ident, row in self.rows.items()
                 if row["ic50_nM"] and not row["endpoint_type"]]
        self.assertEqual(blank, [])


if __name__ == "__main__":
    unittest.main()
```

```python
"""TL-A′ 체크포인트 스윕의 집계와 epoch 선택 (spec §4.2).

선택 규칙은 도킹 전에 확정된 것이며, 결과를 보고 바꾸지 않는다.
암기 지표는 여기서 선택에 쓰이지 않고 보고 컬럼으로만 남는다 - v1에서 암기
꼬리가 하류의 Murcko 신규성 게이트(known_scaffolds.smi)에서 제거되는 것이
확인되었기 때문이다. 다만 신규성을 주장할 때는 이 꼬리가 몇 개 제거되었는지
반드시 함께 보고해야 한다.
"""

from __future__ import annotations

__all__ = ["MIN_EPOCH", "SCAFFOLD_FLOOR", "select_epoch"]

MIN_EPOCH = 100
SCAFFOLD_FLOOR = 700


def select_epoch(rows: list[dict]) -> int | None:
    """규칙을 만족하는 가장 높은 epoch. 없으면 None (= TL-A′ 탈락)."""
    qualifying = [r["epoch"] for r in rows
                  if r["epoch"] >= MIN_EPOCH
                  and r["unique_scaffolds"] >= SCAFFOLD_FLOOR]
    return max(qualifying) if qualifying else None
```

```python
"""autogrid4 GPF 생성과 맵 범위 검증 (spec §7.1).

박스는 dock_unidock.box_from_ligand에서 그대로 가져온다. smina의
--autobox_ligand + --autobox_add 6 규칙을 재현하는 그 함수가 유일한 진실이며,
여기서 다시 계산하면 검색 공간이 조용히 달라진다.

AutoDock-GPU는 리간드가 그리드를 벗어나도 오류를 내지 않는다. 그래서
maps_cover_box를 게이트로 둔다.
"""

from __future__ import annotations

import math
from pathlib import Path

__all__ = ["SPACING", "LIGAND_TYPES", "write_gpf", "maps_cover_box"]

SPACING = 0.375
# 생성 분자가 쓰는 원소 + 수용체의 Ca. HD/OA/NA는 AD4의 극성 수소·수용체 타입.
LIGAND_TYPES = ["C", "A", "N", "NA", "OA", "S", "SA", "HD", "F", "Cl", "Br", "I"]
RECEPTOR_TYPES = ["C", "A", "N", "NA", "OA", "SA", "HD", "CA"]


def _npts(extent: float) -> int:
    n = math.ceil(extent / SPACING)
    return n + 1 if n % 2 else n


def write_gpf(box: dict, receptor: str, out: Path) -> str:
    cx, cy, cz = box["center"]
    npts = [_npts(e) for e in box["size"]]
    lines = [
        f"npts {npts[0]} {npts[1]} {npts[2]}",
        f"gridfld {Path(receptor).stem}.maps.fld",
        f"spacing {SPACING}",
        f"receptor_types {' '.join(RECEPTOR_TYPES)}",
        f"ligand_types {' '.join(LIGAND_TYPES)}",
        f"receptor {receptor}",
        f"gridcenter {cx:.3f} {cy:.3f} {cz:.3f}",
        "smooth 0.5",
    ]
    lines += [f"map {Path(receptor).stem}.{t}.map" for t in LIGAND_TYPES]
    lines += [f"elecmap {Path(receptor).stem}.e.map",
              f"dsolvmap {Path(receptor).stem}.d.map",
              "dielectric -0.1465"]
    out = Path(out)
    out.write_text("\n".join(lines) + "\n")
    return str(out)


def maps_cover_box(gpf: str, box: dict) -> bool:
    """GPF가 정의한 그리드가 주어진 박스를 완전히 덮는가."""
    text = Path(gpf).read_text().splitlines()
    npts = [int(v) for v in
            next(l for l in text if l.startswith("npts")).split()[1:4]]
    return all(n * SPACING >= extent for n, extent in zip(npts, box["size"]))
```

```python
"""AutoDock-GPU 실행과 .dlg 파싱 (spec §7).

박스는 dock_unidock.box_from_ligand를 임포트해 쓴다. 여기서 다시 계산하면
검색 공간이 오류 없이 달라지고, 게이트는 다른 질문에 답하게 된다.

엔진이 Vina에서 AD4로 바뀌므로 affinity 값은 v1과 비교할 수 없다. PLN-1474의
기준값도 이 엔진에서 새로 산출한다.
"""

from __future__ import annotations

import re

from dock_unidock import box_from_ligand  # noqa: F401  (호출자가 재수출해 씀)

__all__ = ["NRUN", "build_command", "parse_dlg", "box_from_ligand"]

NRUN = 20

_ENERGY = re.compile(r"Estimated Free Energy of Binding\s*=\s*(-?\d+\.\d+)")


def build_command(fld: str, ligand: str, out_prefix: str, seed: int) -> list[str]:
    return ["autodock_gpu", "--ffile", fld, "--lfile", ligand,
            "--resnam", out_prefix, "--nrun", str(NRUN), "--seed", str(seed)]


def parse_dlg(text: str) -> list[dict]:
    """.dlg의 DOCKED 블록에서 포즈를 뽑는다.

    에너지가 없어도 포즈는 버리지 않는다 - v1에서 점수 추출 실패가 구조 파싱과
    같은 try 안에 있어 포즈를 0개로 만든 회귀가 있었다.
    """
    poses: list[dict] = []
    block: list[str] = []
    affinity = None
    rank = 0
    for line in text.splitlines():
        if not line.startswith("DOCKED:"):
            continue
        payload = line[len("DOCKED:"):].lstrip()
        if payload.startswith("MODEL"):
            block, affinity = [payload], None
            rank += 1
            continue
        match = _ENERGY.search(payload)
        if match:
            affinity = float(match.group(1))
            continue
        if payload.startswith("USER"):
            continue
        block.append(payload)
        if payload.startswith("ENDMDL"):
            poses.append({"rank": rank, "affinity": affinity,
                          "pdbqt_block": "\n".join(block)})
    return poses
```

```python
"""재도킹 검증 게이트 (spec §7.4).

거리(ⓐⓑ)와 PLIP(ⓓ)이 같은 두 접촉을 이중으로 확인한다. 어긋나면 기록하고
PLIP 판정을 따른다 - 거리는 각도를 보지 않기 때문이다.
"""

from __future__ import annotations

from pose_geometry import CA_CUTOFF, DONOR_CUTOFF

__all__ = ["CRYSTAL_CONTACTS", "RMSD_CUTOFF", "verdict"]

# 8W30 결정 구조의 값. 게이트가 이보다 관대해야 하는 이유의 기준점이다.
CRYSTAL_CONTACTS = {"ca_dist": 2.62, "donor_dist": 2.63}
RMSD_CUTOFF = 2.0


def verdict(measurement: dict) -> dict:
    failed, disagreements = [], []
    if measurement["ca_dist"] > CA_CUTOFF:
        failed.append("ca_dist")
    if measurement["donor_dist"] > DONOR_CUTOFF:
        failed.append("donor_dist")
    if measurement["rmsd"] >= RMSD_CUTOFF:
        failed.append("rmsd")
    if not measurement["plip_metal_ca501"]:
        failed.append("plip_metal_ca501")
    if not measurement["plip_hbond_asn224"]:
        failed.append("plip_hbond_asn224")

    # 거리는 통과하는데 PLIP이 인정하지 않는 경우: 각도 문제의 실물.
    if measurement["ca_dist"] <= CA_CUTOFF and not measurement["plip_metal_ca501"]:
        disagreements.append("ca_dist")
    if measurement["donor_dist"] <= DONOR_CUTOFF and not measurement["plip_hbond_asn224"]:
        disagreements.append("donor_dist")

    return {"passed": not failed, "failed": failed,
            "disagreements": disagreements}
```

```python
"""포즈 PDBQT를 수소 포함 PDB 복합체로 변환한다 (spec §8.0).

PLIP은 donor-H...acceptor 각도를 계산하므로 명시적 수소가 필요하다. PDBQT는
비극성 수소가 병합되어 있어 그대로는 쓸 수 없다.

한 포즈의 실패가 배치를 중단시키면 안 된다. build_complex는 예외를 던지지
않고 None을 반환하며, build_many는 실패 목록을 함께 돌려준다.
"""

from __future__ import annotations

import subprocess
from pathlib import Path

__all__ = ["LIGAND_RESNAME", "build_complex", "build_many"]

LIGAND_RESNAME = "LIG"


def _ligand_pdb(pose_pdbqt: str, out: Path) -> str:
    """obabel로 수소를 붙여 PDB로 변환한다. -h는 pH 인자를 받지 않는다."""
    subprocess.run(
        ["obabel", pose_pdbqt, "-opdb", "-O", str(out), "-h"],
        check=True, capture_output=True, timeout=120,
    )
    return str(out)


def build_complex(pose_pdbqt: str, receptor_pdb: str, out) -> str | None:
    out = Path(out)
    try:
        ligand = _ligand_pdb(pose_pdbqt, out.with_suffix(".lig.pdb"))
        lig_lines = []
        for line in Path(ligand).read_text().splitlines():
            if not line.startswith(("ATOM", "HETATM")):
                continue
            # 수용체와 구별되도록 HETATM/LIG로 다시 쓴다. PLIP은 이 이름으로
            # 리간드를 식별한다.
            lig_lines.append("HETATM" + line[6:17] + LIGAND_RESNAME + line[20:])
        if not lig_lines:
            return None
        receptor = [l for l in Path(receptor_pdb).read_text().splitlines()
                    if l.startswith(("ATOM", "HETATM"))]
        out.write_text("\n".join(receptor + lig_lines + ["END"]) + "\n")
        return str(out)
    except (subprocess.CalledProcessError, subprocess.TimeoutExpired,
            OSError, ValueError, IndexError):
        return None


def build_many(poses: list[str], receptor_pdb: str, out_dir) -> dict:
    out_dir = Path(out_dir)
    out_dir.mkdir(parents=True, exist_ok=True)
    built, failed = [], []
    for pose in poses:
        target = out_dir / (Path(pose).stem + ".complex.pdb")
        result = build_complex(pose, receptor_pdb, target)
        if result is None:
            failed.append((pose, "complex build failed"))
        else:
            built.append(result)
    return {"built": built, "failed": failed}
```

```python
"""PLIP 실행과 XML 리포트 파싱 (spec §8.0).

PLIP은 GPU 구현이 없는 CPU 도구다. K-BDS에서는 cpu64 파티션에서 포즈 단위로
병렬 실행한다. 8gpu는 GPU 사용 여부와 무관하게 시간당 8 node-hour를 과금한다.

상호작용이 하나도 없는 포즈는 정상적인 결과다. 예외가 아니라 빈 리스트로
돌려줘야 배치가 멈추지 않는다.
"""

from __future__ import annotations

import xml.etree.ElementTree as ET

__all__ = ["INTERACTION_KINDS", "parse_report"]

INTERACTION_KINDS = ("metal_complexes", "hbonds", "hydrophobic_contacts",
                     "pi_stacking", "salt_bridges", "water_bridges",
                     "halogen_bonds")

# PLIP XML의 컨테이너/항목 태그와 우리 키의 매핑.
_TAGS = {
    "metal_complexes": ("metal_complexes", "metal_complex"),
    "hbonds": ("hydrogen_bonds", "hydrogen_bond"),
    "hydrophobic_contacts": ("hydrophobic_interactions", "hydrophobic_interaction"),
    "pi_stacking": ("pi_stacks", "pi_stack"),
    "salt_bridges": ("salt_bridges", "salt_bridge"),
    "water_bridges": ("water_bridges", "water_bridge"),
    "halogen_bonds": ("halogen_bonds", "halogen_bond"),
}

_INT_FIELDS = {"resnr"}
_FLOAT_FIELDS = {"dist", "dist_h-a", "dist_d-a", "don_angle", "centdist",
                 "angle", "offset"}


def _coerce(tag: str, text: str):
    if tag in _INT_FIELDS:
        return int(text)
    if tag in _FLOAT_FIELDS:
        return float(text)
    return text


def parse_report(xml_text: str) -> dict:
    root = ET.fromstring(xml_text)
    record = {kind: [] for kind in INTERACTION_KINDS}
    for kind, (container, item) in _TAGS.items():
        for node in root.iter(container):
            for entry in node.findall(item):
                record[kind].append({
                    child.tag: _coerce(child.tag, (child.text or "").strip())
                    for child in entry if child.text
                })
    return record
```

```python
"""PLIP 검증 게이트 (spec §8.0).

8W30 결정 복합체에서 기록된 네 상호작용을 재현하지 못하면 PLIP을 채택하지
않는다. T-shaped 스택이 결정적 확인 항목이다 - v1의 거리 기준(centroid
5.5 Å)이 8W30 자신의 6.21 Å T-stack을 기각했고, 그것이 PLIP 도입의 이유다.
"""

from __future__ import annotations

__all__ = ["MIDAS", "ASN224", "TYR178", "HYDROPHOBIC_POCKET", "crystal_verdict"]

MIDAS = ("B", 501)
ASN224 = ("B", 224)
TYR178 = ("A", 178)
HYDROPHOBIC_POCKET = {("B", 133), ("B", 186), ("B", 187), ("B", 225)}


def _residues(entries):
    return {(e["reschain"], e["resnr"]) for e in entries}


def crystal_verdict(record: dict) -> dict:
    missing = []
    if MIDAS not in _residues(record["metal_complexes"]):
        missing.append("metal_ca501")
    if ASN224 not in _residues(record["hbonds"]):
        missing.append("hbond_asn224")
    stacks = [s for s in record["pi_stacking"]
              if (s["reschain"], s["resnr"]) == TYR178]
    if not stacks:
        missing.append("pi_stack_tyr178")
    if not (_residues(record["hydrophobic_contacts"]) & HYDROPHOBIC_POCKET):
        missing.append("hydrophobic_pocket")
    return {"passed": not missing, "missing": missing}
```

```python
def _ring_plane_angle(ring_a: np.ndarray, ring_b: np.ndarray) -> float:
    """두 방향족 고리 평면 사이의 각(도). 0-90으로 접는다.

    T-shaped 스택은 두 고리를 수직으로 놓아 centroid를 벌린다 - 8W30은
    centroid 6.21 Å에 고리각 74.6°다. 이 값을 기록으로 남기는 이유는,
    centroid 거리만 보면 결정 구조 자신이 기각되기 때문이다.
    """
    def normal(ring):
        centered = ring - ring.mean(axis=0)
        return np.linalg.svd(centered)[2][2]
    cos = abs(float(np.dot(normal(ring_a), normal(ring_b))))
    return float(np.degrees(np.arccos(min(1.0, cos))))
```

```python
"""PLIP 레코드에 대한 게이트 판정 (spec §8.2).

판정 규칙은 cpd 25 도킹 전에 확정된 것이다. 결과를 보고 규칙을 바꾸지 않는다.

기본 게이트는 'Ca501 metal complex AND 2차 극성 앵커'이고, 2차 앵커의 정의만
cpd 25의 결과로 결정된다. Tyr178 π-stacking과 Leu225 측쇄 소수성 접촉은
어떤 경우에도 게이트가 되지 않는다 - 전자는 통과 집단에서 방향족 고리 보유의
농축이 1.03배(=없음)로 측정되었고, 후자는 64.3%로 변별력이 약하다.
"""

from __future__ import annotations

__all__ = ["MIDAS", "ASN224", "LEU225", "BACKBONE_SEGMENT",
           "decide_gate", "passes"]

MIDAS = ("B", 501)
ASN224 = ("B", 224)
LEU225 = ("B", 225)
BACKBONE_SEGMENT = {("B", 223), ("B", 224), ("B", 225), ("B", 226)}


def _has_metal(record: dict) -> bool:
    return any((e["reschain"], e["resnr"]) == MIDAS
               for e in record["metal_complexes"])


def _hbond_residues(record: dict) -> set:
    return {(e["reschain"], e["resnr"]) for e in record["hbonds"]}


def decide_gate(cpd25_record: dict) -> str:
    if not _has_metal(cpd25_record):
        return "unchanged_no_pose"
    residues = _hbond_residues(cpd25_record)
    if ASN224 in residues:
        return "asn224"
    if LEU225 in residues:
        return "segment"
    return "midas_only"


def passes(record: dict, gate: str) -> bool:
    if not _has_metal(record):
        return False
    if gate == "midas_only":
        return True
    residues = _hbond_residues(record)
    if gate == "asn224" or gate == "unchanged_no_pose":
        return ASN224 in residues
    if gate == "segment":
        return bool(residues & BACKBONE_SEGMENT)
    raise ValueError(f"unknown gate: {gate}")
```

```python
PERMEABILITY_MARGIN = 0.5

DEFAULT_THRESHOLDS = {
    "permeability_margin": PERMEABILITY_MARGIN,
    "affinity_reference": None,   # 실행 시 PLN-1474의 best passing pose
    "toxicity_reference": None,   # 실행 시 PLN-1474의 동등 평균

def apply_filters(rows, reference, thresholds=None):
    """spec §9.1의 4단 필터. 모든 기준이 PLN-1474 상대값이다.

    thresholds를 넘기면 사후 완화가 되며, 완화된 값이 결과에 기록된다 -

    항상 기본값으로 따로 계산해야 한다.
    """
    t = dict(DEFAULT_THRESHOLDS)
    t.update(thresholds or {})
    margin = t["permeability_margin"]

    funnel = {"input": len(rows)}
    rows = [r for r in rows if r["gate_pass"]]
    funnel["gate"] = len(rows)
    rows = [r for r in rows if r["caco2"] - reference["caco2"] > margin]
    funnel["permeability"] = len(rows)
    rows = [r for r in rows if r["affinity"] < reference["affinity"]]
    funnel["affinity"] = len(rows)
    rows = [r for r in rows if r["toxicity"] < reference["toxicity"]]
    funnel["toxicity"] = len(rows)

    return {"survivors": rows, "funnel": funnel, "thresholds": t}
```

```python
"""선택성 Δ와 rank-sum (spec §10).

서로 다른 수용체 간 절대 점수를 비교하지 않는다. 같은 리간드의 두 수용체
점수 차이를 쓰면, 리간드 크기·원자 수에 비례하는 계통 오차가 약분된다.
아이소폼별 스케일 차이는 순위화 단계에서 흡수된다.
"""

from __future__ import annotations

__all__ = ["ISOFORMS", "PAN_AV_REFERENCES", "SELECTIVE_REFERENCES",
           "delta", "rank_sum", "calibration_verdict"]

ISOFORMS = ("avb3", "a5b1", "avb6", "avb8")

# 측정된 ground truth. CWHM-12: αvβ1 1.8 / αvβ3 0.8 / αvβ6 1.5 / αvβ8 0.2 nM.
# GLPG0187: 1.3 / 3.7 / 1.4 / 1.2 nM. 둘 다 αvβ1 선택적이 아니다.
PAN_AV_REFERENCES = ("CWHM-12", "GLPG0187")
# 문헌상 αvβ1 선택적이라고 보고된 화합물.
SELECTIVE_REFERENCES = ("PLN-1474", "CHEMBL4649232")


def delta(off_target: dict[str, float], avb1: float) -> dict[str, float]:
    """Δ_s = affinity(s) − affinity(αvβ1). 양수일수록 선택적."""
    return {iso: score - avb1 for iso, score in off_target.items()}


def rank_sum(deltas: dict[str, dict[str, float]]) -> dict[str, float] | None:
    """아이소폼별로 Δ 내림차순 순위를 매기고 역순 점수를 합산한다.

    검증을 통과한 아이소폼이 하나도 없으면 None을 반환한다 - 판정 기준 7번은
    그 경우 unevaluable로 기록된다.
    """
    isoforms = sorted({iso for d in deltas.values() for iso in d})
    if not isoforms:
        return None
    n = len(deltas)
    scores = {label: 0.0 for label in deltas}
    for iso in isoforms:
        ordered = sorted(deltas, key=lambda m: deltas[m].get(iso, float("-inf")),
                         reverse=True)
        for position, label in enumerate(ordered):
            scores[label] += n - position
    return scores


def calibration_verdict(scores: dict[str, float]) -> dict:
    """pan-αv 참조군이 선택적 참조군보다 낮게 나와야 한다."""
    pan = [scores[m] for m in PAN_AV_REFERENCES if m in scores]
    selective = [scores[m] for m in SELECTIVE_REFERENCES if m in scores]
    if not pan or not selective:
        return {"passed": False, "violations": ["missing reference compounds"]}
    floor = min(selective)
    violations = [m for m in PAN_AV_REFERENCES
                  if m in scores and scores[m] >= floor]
    return {"passed": not violations, "violations": violations}
```

```python
"""성공 판정 기준 (spec §2).

항상 사전등록 임계값으로 계산한다. 리드 선정(§9)의 사후 완화와 섞이면
반증 조항이 무의미해지므로, 이 모듈은 select_leads의 완화된 thresholds를
받지 않는다.

한 분자가 모든 기준을 만족해야 한다. 서로 다른 분자가 나눠 만족하는 것은
성공이 아니다.
"""

from __future__ import annotations

from select_leads import PERMEABILITY_MARGIN

__all__ = ["CRITERIA", "evaluate"]

CRITERIA = [
    {"name": "interaction_gate",
     "test": lambda r, ref: r["gate_pass"]},
    {"name": "permeability",
     "test": lambda r, ref: r["caco2"] - ref["caco2"] > PERMEABILITY_MARGIN},
    {"name": "affinity",
     "test": lambda r, ref: r["affinity"] < ref["affinity"]},
    {"name": "toxicity",
     "test": lambda r, ref: r["toxicity"] < ref["toxicity"]},
    {"name": "murcko_novel",
     "test": lambda r, ref: r["murcko_novel"]},
    {"name": "alert_free",
     "test": lambda r, ref: r["alert_free"]},
    {"name": "selectivity",
     "test": lambda r, ref: r["selectivity"] > ref["selectivity"]},
]


def evaluate(rows: list[dict], reference: dict,
             selectivity_evaluable: bool) -> dict:
    """기준 1-7을 평가한다.

    selectivity_evaluable=False는 §10.4의 보정 게이트 미통과를 뜻한다.
    기준 7은 unevaluable로 기록하며, 실패로 처리하지도 성공으로 주장하지도
    않는다 - 즉 성공 여부 계산에서 제외한다.
    """
    active = [c for c in CRITERIA
              if c["name"] != "selectivity" or selectivity_evaluable]

    qualifying = [r for r in rows
                  if all(c["test"](r, reference) for c in active)]

    criteria = []
    for c in CRITERIA:
        if c["name"] == "selectivity" and not selectivity_evaluable:
            criteria.append({"name": c["name"], "status": "unevaluable",
                             "n_passing": None})
            continue
        n = sum(1 for r in rows if c["test"](r, reference))
        criteria.append({"name": c["name"],
                         "status": "met" if n else "unmet", "n_passing": n})

    return {
        "success": bool(qualifying),
        "qualifying": [r["label"] for r in qualifying],
        "criteria": criteria,
        # 반증 조항: 아무 분자도 만족하지 못하면 그대로 보고한다.
        "falsification": None if qualifying else (
            "사전등록 기준을 모두 만족하는 분자가 없다. 카복실레이트-투과성-"
            "독성 긴장이 표적 내재적일 가능성의 증거이며, 그 자체가 결과다."
        ),
    }
```
